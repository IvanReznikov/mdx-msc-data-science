# MDX-Bazario W8L16 leaderboard (private Space)

Two tabs: **Submit** (student_id + CSV) and **Leaderboard** (public scores on
half of the hidden rows; flip `REVEAL_PRIVATE` at the deadline for final standings).

See `DEPLOY.md` in the course repo (`private/tools/leaderboard_site/`) for the
full deployment runbook — keys and state live in private HF dataset repos
attached via the Space secrets `HF_TOKEN`, `KEYS_REPO`, `STATE_REPO`.
