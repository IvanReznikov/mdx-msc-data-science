How it works
  • The visible score is computed on half of the hidden rows. Final standings after the deadline use the other half — exactly like Kaggle's public/private split, so probing the leaderboard is a losing strategy.

  • Use the same name every time — that’s how your scores are tracked. The holdout truth is never published.
