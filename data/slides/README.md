# data/slides — the seeded dataset behind the slide numbers

**One dataset: `listings.csv`** — 480 synthetic-but-realistic real-estate listings
(generated by `private/generators/generate_slide_dataset.py`, seed 20260903; ground truth in
`private/homework_keys/slide_datasets_key.json`). Chosen because it is universal, it spans
the whole syllabus, and it matches the official Lab 2/6/7 dataset (`Real_estate.csv`)
students already meet.

Columns: `listing_id, neighborhood (6), rooms, area_m2, age_years, distance_center_km,
floor, parking (0/1), price_kusd, views_week, listed_date`.

## Planted, round-number headlines (survive regeneration)

| Number | Value | Teaching use |
|---|---|---|
| mean price | **exactly 500.0k** | L02 centre; the seed shifts it last so it stays exact |
| median price | **433k** | mean-vs-median skew story (two ~2.5M penthouses) |
| corr(price, area) | **≈ 0.71** | L07 OLS teaser |
| parking share | **exactly 30%** | Bernoulli p=0.30, E=0.30, V=0.21 |
| views_week | **Poisson(λ≈12)** | counts teaching |
| log-price skew | **≈ 0** | lognormal: "take logs, the skew vanishes" |
| neighbourhoods | Marina ≈ 2.2× Old Town per m² | L03 open question: real or noise? |

## Rules

- The Quarto decks quote these numbers **live** (jupyter engine executes at render); the
  mirror notebook is `slides_materials/L02. …/slide_numbers.ipynb`. Paths from a deck:
  `../../data/slides/listings.csv`.
- Never hand-edit the CSV — change the generator (keep planted numbers exact, update the
  key file) and regenerate.
- Figures/GIFs for slides are code-generated from this file
  (`slides_materials/L02. …/make_figures.py`, `animate_histogram.py`) or drawn in
  excalidraw (`slides_materials/excalidraw/`) — see that folder's README for the
  animation workflow.
